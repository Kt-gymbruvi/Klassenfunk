# Klassenfunk

Live-Abstimmungen für den Unterricht: Wortwolke, Umfrage, offene Fragen, Skala, Rangfolge, 100 Punkte, 2×2-Raster, Fragen der Klasse, Reaktionen und Tempo-Barometer.

- Schüler: https://kt-gymbruvi.github.io/Klassenfunk/ → „Mitmachen“, PIN vom Beamer eingeben. Kein Name, kein Konto.
- Lehrkraft: „Präsentieren“ → anmelden (gleiches Konto wie Quizzo) → Präsentation anlegen → ▶ Präsentieren.

## Entwickeln
```bash
npm ci
npm run dev
npm test
npm run build
```

Einrichtung der Datenbank: [`supabase/EINRICHTUNG.md`](supabase/EINRICHTUNG.md). Regeln für die Weiterentwicklung: [`CLAUDE.md`](CLAUDE.md).
